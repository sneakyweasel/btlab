# Literature registry

Structured metadata lives under `literature/`. The Python API is
`research.literature`.

Each record has:

- title, authors, year
- DOI / arXiv / URL
- problem area
- relevant concepts
- project relationship (`known`, `reproduced`, `extended`,
  `independent`, `refuted`)
- status and notes

so preprint claims are not adopted as theorems.
