# Juggler maximal odd-run block map \(Q\)

Status: **EXPLORATORY**

Standalone application phase on the Juggler floor-power map. It is
**not** a Research Engine control-layer experiment, not a
run-length automaton, not a PE-scalar reopen, not a residue
modulus search, not empty-cell dynamics, not Paper A, and not a
claim that every positive integer reaches 1.

After itinerary-grammar PARK, the leftover is the arithmetic map
that actually produces the next run length. This phase asks
whether that map admits any exact state smaller than the integer
landing.

## Problem

On residual `AboveAnchor` odd landings, does the maximal odd-run
block map \(Q\) have a small exact state in which consecutive
blocks obey a transition law, or is the residual a genuinely
high-dimensional arithmetic dynamical system?

## Exact statement

For odd \(x\ge 3\), let \(a(x)\) be the unique integer \(a\ge 1\)
such that \(T^j(x)\) is odd for \(0\le j<a\) and \(T^a(x)\) is
even. The block includes that terminal even state as an interior
point. Set

\[
Q(x)=T^{a(x)+1}(x).
\]

The landing \(Q(x)\) may be odd or even. Restrict to

\[
\mathcal D_n
=
\{\text{odd landings }x\ge n
\text{ on the AboveAnchor path of }n\}.
\]

On leftover controls and on odd starts \(n<2001\), decide whether
any exact descriptor coarser than the integer \(x\) predicts
\(a(Q(x))\), whether a two-block or three-block return law holds,
and whether any orbit repeats an integer block endpoint. Isolated
`OE` contracts is already Lean and is not restated.

## Balanced-ternary formulation

## Counterexamples

Ordinary terminating orbits, not `MinimalNonTerm` witnesses.

- “a finite intrinsic descriptor of \(Q^3(n)\) distinguishes
  the `365`/`1517` branch” — at \(4447\) versus \(33811\),
  the values of \(x\), \(Q(x)\), the previous endpoint, the
  first odd defect, the closing remainder, and \(Q(x)-x\) all
  differ. The only shared state is the already-refuted
  prefix \((2,2,2)\) with \(\alpha=729/512\). The minimal
  predictor is the integer landing.
- “\(Q(x)<x\) and \(Q(x)\ge n\) forces a stricter next
  domain” — on `1517`, \(33811\to 2493\ge 1517\), then
  \(2493\to 539470\).
- “\(Q(x)>x\) forces later contraction below \(x\)” — on
  odd \(n<2001\), an expansion is followed by a still-larger
  \(Q^2\) in \(153\) blocks.
- “\((a,\mathrm{sign})\) is a transition state” — after an
  expanding \(a=2\) block the next run takes every value in
  \(\{1,\ldots,9\}\) on \(n<2001\).
- “the pair \((a_{i-1},a_i)=(2,2)\) determines \(a_{i+1}\)” —
  the next run is \(1,2,3,4,\) or \(9\).

## Results

Classification **BLOCK_MAP_Q_PARK**.

On leftover controls the odd \(Q\)-orbits are

- \(365\colon 365\to 763\to 1749\to 4447\to 12707\to 1196\),
- \(1517\colon 1517\to 3789\to 10613\to 33811\to 2493\to 539470\),
- \(501\) joins the \(365\) spine at \(763\) after an even
  landing,
- \(6187\) exits by `OE` from \(11189\) to \(1087<6187\).

The block starts at an odd state and ends at the post-even
landing; the even state is interior. No leftover orbit, and no
odd start \(n<2001\), repeats an integer block endpoint. The
canonical collision after three `OOE` blocks is the pair of
landings \(4447\) and \(33811\). They share no tested intrinsic
coordinate. Every proper compression of the current block
(run length and expansion sign, previous run, first odd
defect, closing remainder) fails to determine the next run on
the residual window. Two-block return inequalities fail in
both directions. The map \(Q\) is deterministic on the integer
\(x\); that integer is the smallest exact predictive state.

This is the third case of the attack's dichotomy: no exact
recurrence and no block-level drift from a compressed state.
The current state description, once compressed, is
insufficient. `MinimalNonTerm` still implies every block
endpoint stays \(\ge n\), but that tautology does not produce
a descent-versus-recurrence theorem for \(Q\).

## Decision

**PARK**. The falsifier holds: \(Q\) is no more predictive than
the raw landing. No exact relation between consecutive block
endpoints survived except the definition of \(Q\). Candidate
finite descriptors fail. No numerical \(Q\)-cycle appeared on
the window. The isolated-`OE` contraction is already Lean and
is not a multi-block return law.

Best next question: a global, not locally finite-state,
property of an infinite residual \(Q\)-orbit — if one exists —
that would force either exact endpoint recurrence or an
endpoint below the anchor. Do not search for another scalar
Lyapunov function. The episode-sequence restatement of that
question is closed in
[juggler_macro_event.md](juggler_macro_event.md).
