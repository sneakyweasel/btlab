# Juggler is Collatz one exponential level up

Generated by `python -m research.juggler_sequence.collatz_bridge`.

## The shared walk

- steps `log(3/2) = 0.405465108108` and `-log 2 = -0.693147180560`
- Collatz carries them on `log x`, Juggler on `log log n`
- worst measured Juggler increment error from a 21-digit seed: `1.10e-09`

## The shared count

- undecided Collatz residue classes against `N_d`, depths 4 to 10: agree = `True`
- parity map bijective on `Z/2^d`: `{'4': True, '6': True, '8': True}`

## Where they part

For Collatz the parity word is a function of x mod 2^d and the map to {0,1}^d is a bijection, so every word has density exactly 2^(-d): Terras, arithmetic and free. For Juggler the word is a function of frac(n^(3/2)) and its relatives, and equal densities are Hypothesis FD, which is open. Same combinatorics, incompatible arithmetic.

## What this does not say

This is not an equivalence and not a conjugacy. It moves no bound in either problem, proves nothing new about Collatz beyond restating Terras, and proves nothing about Juggler at all. Its content is a partition: results that use only word densities belong to both problems, results that use how orbits realise words belong to Juggler and rest on Hypothesis FD. Juggler is not an easier Collatz -- it is Collatz's word problem plus a Weyl-sum problem, and both stall at the same wall.
